# SpotiCraft

- [`app/`](app/) — **Bloomee**, native Windows desktop music app (C++
  Win32 + Direct2D, single EXE). Spotify desktop ki measured UI/UX
  ([`docs/spotify-desktop-study.md`](docs/spotify-desktop-study.md)),
  playback Media Foundation/WASAPI. Build: `app/build.cmd`.
- [`music-api/`](music-api/) — BloomeeTunes ke plugin contract par bani
  unified Music REST API (JioSaavn + YouTube Music) — app ke C++ port ki
  reference implementation.
